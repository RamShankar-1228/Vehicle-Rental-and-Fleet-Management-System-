# Vehicle Rental and Fleet Management System (SB Group-12 Mini Project)

A clean, responsive front-end web application designed to simplify the process of browsing, booking, and managing rental vehicles. The system allows customers to view available vehicles, check rental rates and specifications, make bookings, while providing an admin dashboard for fleet and booking management.

## 🛠️ Tech Stack

- **HTML5** — Semantic structure and page layout
- **CSS3** — Styling, Flexbox, Grid and Responsive Design
- **JavaScript** — Dynamic functionality, form validation and application logic
- **localStorage** — Client-side data persistence

---

## 🚗 Core Features

- Browse available rental vehicles
- View vehicle details and rental rates
- Search and filter vehicles
- Select rental dates and make bookings
- Check vehicle availability
- Booking form validation
- Admin dashboard for fleet management
- Add, edit and remove vehicles
- View and update booking status
- Persistent vehicle, customer and booking data using `localStorage`
- Responsive design for desktop, tablet and mobile devices

---

## 👤 User Roles

### Customer
- Browse available vehicles
- View vehicle details
- Check rental rates and availability
- Select rental dates
- Make a vehicle booking

### Admin
- Manage the vehicle fleet
- Add new vehicles
- Update vehicle information
- Remove vehicles
- Monitor vehicle availability
- View and update booking status
